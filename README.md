# GYM LEADER DNA

20문항, 18개 독립 타입, 두 순위의 대표 인물, 전투 스타일 분석과 타입별 6마리 파티를 제공하는 한국어 정적 사이트입니다.

## 실행과 검증

이 폴더에서 `python3 -m http.server 8000 `를 실행하고 http://localhost:8000 에 접속하세요. 사이트 파일 전체를 GitHub Pages 등 정적 호스팅에 올릴 수도 있습니다. JSON을 불러오므로 파일 직접 열기는 지원하지 않습니다.

`node test.mjs`로 데이터 무결성, 18개 결과 도달 가능성, 결정론, V5 예시 파티를 검증합니다.

## 파일 구성

- index.html / style.css / app.js: 반응형 화면, 진행, 이전, 응답 저장, 결과와 파티 전환
- questions.json: 원 대화 V5의 20문항/80선택지
- engine.mjs: 점수표 생성, 정규화와 동점 규칙
- data.json: 18타입, 대표 인물, 108개 파티 슬롯, 포켓몬 83종의 결과 데이터
- assets: 포켓몬 공식 일러스트 83개, 트레이너 공식 게임 스프라이트 18개

## 채점 설명

실행·분석·끈기·협력·창의·성장의 6개 축을 타입별 벡터와 연결합니다. 각 선택지는 모든 타입에 0~4 정수 점수를 부여합니다. 타입마다 문항별 가능한 최소·최대 합계를 계산하고 `(원점수-가능최소)/(가능최대-가능최소)*100`으로 정규화합니다. 합계 100%가 되는 확률이 아닙니다. 동점은 원점수 내림차순, engine.mjs의 고정 타입 순서로 결정합니다. 난수·시간·서버를 사용하지 않습니다. 전투 스타일은 별도의 키워드별 선택 횟수를 사용합니다.

기존 V5에는 숫자 점수표나 실제 20개 응답 기록이 없어 웹사이트용 새 점수표를 설계했습니다. 최신 불꽃/전기 결과는 파티 구성과 대표 인물의 내용 회귀 테스트로 사용했습니다. 과거 응답 결과를 재현한다고 주장하지 않습니다. 검증된 심리검사가 아닌 재미용 팬 콘텐츠입니다.

## 이미지 출처

포켓몬: https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/other/official-artwork (공식 일러스트 보관본)

트레이너: https://play.pokemonshowdown.com/sprites/trainers/ (공식 게임 스프라이트 보관본)

파일명은 포켓몬 ID 또는 트레이너 영문명에 대응합니다. 자체 생성 이미지와 팬아트를 사용하지 않았습니다. 트레이너는 픽셀 게임 스프라이트입니다. 권리는 Pokémon/Nintendo/Creatures/GAME FREAK 등 각 권리자에게 있습니다. Google Fonts 연결이 없으면 시스템 글꼴을 사용하며, 포켓몬 자산은 모두 로컬에 있습니다.

추천은 특정 세대의 대회 최적화가 아닌 본가 싱글 배틀 컨셉 파티입니다. 작품과 참가 규칙에 따라 기술·특성·도구를 확인하세요. 소원의 별 등장 및 구현 여부는 모두 미확인입니다. 응답은 브라우저 localStorage에만 저장됩니다.

## 이미지와 문항 UI 수정

히스이 조로아크는 10239, 알로라 나인테일은 10104로 연결을 수정했습니다. asset-manifest.json에 전체 83종의 영문 폼 이름·한국어 종 이름·타입·공식 일러스트 경로를 기록하고 test.mjs에서 대조합니다.

20문항의 각 4개 선택지에 이미지 카드를 연결했습니다. 공식 Pokémon LEGENDS Z-A 게임 장면 19개를 문맥에 맞게 재사용합니다. 원본 경로는 scene-manifest.json, 선택지별 연결과 대체 텍스트는 questions.json에 있습니다. 공식 출처: https://legends.pokemon.com/en-us/gameplay/

마지막 응답 후 3초간 분석 애니메이션이 표시되고 결과로 전환됩니다. 분석 중 새로고침 시에는 응답이 보존된 테스트로 돌아가며 다시 결과를 요청할 수 있습니다.
